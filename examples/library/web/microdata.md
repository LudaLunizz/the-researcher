# Microdata basics (example document)

## Section 1

Structured data tells a search engine what a page is about: a product, an event, a person. Keep it in the page markup, make sure it matches what a visitor sees, and test it with the validator before publishing. (Example text, made up for the README pictures. Part 1 of 2.)
