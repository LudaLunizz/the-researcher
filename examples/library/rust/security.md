# Rust security checklist (example document)

## Section 1

Audit dependencies with cargo audit and cargo vet. Pin versions in Cargo.lock and commit it for binaries. Review build scripts, because they run on your machine at build time. Turn on overflow checks in release builds when speed allows. Keep the number of crates small and prefer ones with several maintainers. (Example text, made up for the README pictures. Part 1 of 5.)
